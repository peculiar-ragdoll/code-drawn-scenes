# Examples

Scenes made with this skill, kept for people to look at. **Don't point a builder at this folder**, and don't put it in a
brief: a finished scene reads as a suggestion, and builders start reproducing its subjects. The same goes for the
skill's rules, which never name scene objects.

Each example has the scene (one self-contained HTML file: open it in a browser), a preview, the brief the builder was
given (verbatim, except that the run's local folder path is replaced by a placeholder), and the credits for the
reference images it was given (the images themselves aren't included).

| example | what | how it was made |
|---|---|---|
| [last-bowl](last-bowl/) | A rainy side street at night with a ramen stall, in the manner of 1930s WPA screen-print posters. Canvas2D, animated: rain, splashes, drips, ripples, steam and the lantern. | One-shot: an independent builder subagent from the brief and six reference images, then two rounds of adversarial review, each followed by a fresh fix pass. |
